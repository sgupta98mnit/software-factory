# Terminal run evidence

An operator can download a versioned JSON evidence packet for a terminal Autopilot run (done, failed or cancelled), including after its worktrees have been removed. The packet uses durable SQLite records and a verified audit snapshot. It never uses a moved integration branch as proof of the completed artifact: only a recorded completion/failure event can supply that commit. Git availability is checked separately; missing records/objects are explicit.

The packet contains run identity/status/timestamps, policy hash, reported costs and budget; work orders with acceptance criteria, controls and linked check/attempt IDs; gate outcomes and output digests; agent role/profile/conversation/status/cost and constrained verdict; Inbox decision metadata; control-to-work-order mappings; audit sequence/hash checkpoint; and limitations. Full goals, prompts, raw agent results, gate output, Inbox bodies and notes, and audit payloads are omitted. Work order criteria/titles remain operator-authored content and should be reviewed before sharing.

Checks in the current ledger lack a tested-commit field. Label that association unrecorded. Security scans and independent validation are unrecorded until those subsystems produce trusted records. A merged work order or a control label is not an assertion that each criterion/control passed.

`POST /sf-api/autopilot/runs/:id/evidence` returns `{ packet, digest: { algorithm: 'sha256', canonicalization: 'sf-canonical-json-v1', value } }`. Hash only `packet` using the existing canonical JSON serializer (recursive sorted object keys, array order retained, undefined object members omitted). This detects changes; it is unsigned and does not authenticate a producer. Generation is serialized with run actions, takes one ledger snapshot, drains prior audit writes and verifies one audit snapshot. Audit the export with the packet hash and artifact SHA, without content. Return 404 for a missing run, 409 for an active run or invalid audit chain, and a safe error if the audit cannot be parsed.

Canvas exposes Download evidence for terminal runs. Clicking fetches the packet and saves JSON through a temporary object URL; duplicate clicks are disabled while pending, URLs are revoked and failures stay visible with retry available. Copy follows factory localization and Canvas theme tokens. API and UI require no new dependencies or upstream Canvas edits.
